# AI-ADAPTIVE-TRAFFIC-SIGNAL-MANAGEMENT-USING-ML
An intelligent traffic management system that uses Machine Learning (ML) and Computer Vision to analyze real-time road congestion and dynamically adjust traffic signal timings to optimize traffic flow.

## Features
- **Real-time Vehicle Detection:** Detects and counts vehicles at intersections using computer vision.
- **Dynamic Signal Control:** Adjusts green light durations adaptively based on traffic density rather than fixed timer intervals.
- **Congestion Reduction:** Prioritizes lanes with higher vehicle density to minimize idle times and emissions.
- **Analytics Dashboard:** Visualizes traffic flow metrics and model accuracy.

## Tech Stack
- **Language:** Python
- **Libraries & Frameworks:** OpenCV, YOLO / CNN, TensorFlow / PyTorch, Pandas, NumPy
- **Interface:** Streamlit / Flask (optional dashboard)
